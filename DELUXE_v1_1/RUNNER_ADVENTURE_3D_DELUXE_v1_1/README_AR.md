# RUNNER ADVENTURE 3D
## مشروع لعبة عدّاء ومغامرة ثلاثية الأبعاد — العربية أولاً

**المحرك المستهدف:** Godot 4.4.1 Stable  
**المنصة المستهدفة:** Android ARM64 (`arm64-v8a`)  
**لغة البرمجة:** GDScript  
**حالة المستودع:** المرحلة 1 — تأسيس المشروع والبنية السحابية

---

## الحالة الحالية بوضوح

هذه الحزمة هي بداية تنفيذ منظمة وليست الإصدار النهائي من اللعبة.

### مكتمل في المرحلة الأولى
- إنشاء مشروع Godot بإعدادات مبدئية متوافقة مع Godot 4.4.
- تحديد مشهد بدء عربي.
- إضافة مدير حفظ محلي بإصدار بيانات ودمج آمن للقيم الافتراضية.
- إضافة نقطة دخول أولية للمشهد ثلاثي الأبعاد.
- إضافة أيقونة SVG أصلية مؤقتة للمشروع.
- إعداد ملفات Dev Container لتطوير Ubuntu 24.04.
- إضافة سير عمل GitHub Actions للتحقق من المشروع باستخدام Godot 4.4.1.
- إعداد ملف تعليمات عربي.

### لم يكتمل بعد
- النموذج ثلاثي الأبعاد النهائي للشخصية والهيكل العظمي والحركات.
- عالم الصحراء والمسار الإجرائي.
- العقبات والعملات والقدرات.
- المتجر والمهام والإنجازات.
- واجهات RTL النهائية والخط العربي المضمّن.
- الصوت والمؤثرات النهائية.
- أيقونات Android التكيفية النهائية.
- تصدير APK واختباره على جهاز Android فعلي.

لا تعتبر أزرار المتجر والمهام والإعدادات في هذه المرحلة وظائف مكتملة؛ إنها عناصر واجهة أولية فقط.

## فتح المشروع

1. ارفع مجلد المشروع إلى مستودع GitHub جديد باسم `RUNNER_ADVENTURE_3D`.
2. افتح المستودع في GitHub Codespaces.
3. انتظر اكتمال إعداد الحاوية.
4. ثبّت Godot 4.4.1 Stable وقوالب التصدير المطابقة له داخل Codespace.
5. افتح المشروع من Godot باستخدام `project.godot`.

## متطلبات Android المستهدفة

توضح وثائق Godot 4.4 أن مسار التصدير يعتمد على Java 17 وAndroid SDK. الحزم المستهدفة لهذا المشروع:

- Android SDK Platform 34
- Android Build Tools 34.0.0
- Android Platform Tools
- Android Command-line Tools (latest)
- CMake 3.10.2.4988404
- NDK 23.2.8568313

يجب تثبيت قوالب تصدير Godot 4.4.1 المطابقة للمحرّك. لا يكفي وجود المحرّك وحده.

## التصدير

بعد ضبط مسارات Java وAndroid SDK وتثبيت قوالب التصدير المطابقة، أضف/تحقق من إعداد Android ARM64 في إعدادات التصدير، ثم نفّذ:

```bash
godot --headless --path . --editor --quit
godot --headless --path . --export-debug "Android" build/runner-adventure-debug.apk
```

هذا الأمر لن ينجح قبل إعداد قالب Android وملف التصدير المسمى `Android`.
